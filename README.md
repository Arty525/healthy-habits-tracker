# Трекер полезных привычек
Этот проект представляет собой backend-часть SPA веб-приложения для отслеживания полезных привычек.
Функционал приложения позволяет добавлять пользователям свои привычки, указывать к ним награду
в виде чего-то приятного или выполнения приятной привычки. Так же пользователи могут делать свои
привычки публичными. Пользователь может настроить напоминание о выполнении действий через телеграм бота.
При подключении телеграм бота к профилю пользователя происходит подтверждение Telegram ID
с помощью кода верификации.

## Порядок установки и запуска проекта:

Для запуска проекта необходимо клонировать репозиторий на ваш компьютер, установить все необходимые
программы, установить все зависимости, создать бота в Telegram, заполнить файл .env
и выполнить миграции.
Для тестов можно добавить тестовые данные.

### Необходимые программы:
    
    - PostgreSQL

    - Python 3.x

    - Redis

### Установка зависимостей
    
Для установки зависимостей введите в терминале вашей IDE команду:
    
    pip install -r requirements.txt

### Выполнение миграций

Перед выполнением миграций вам необходимо вручную создать базу данных в PostgreSQL и занести данные в
файл .env согласно шаблону(.env_example).
Для выполнения миграций введите в терминале команду:
    
    python manage.py migrate

### Кастомные команды

В приложении настроены кастомные команды для добавления тестовых данных в БД.

    python manage.py add_all_data # добавляет пользователей и привычки

    python manage.py add_users # добавляет пользователей

    python manage.py add_habits # добавляет привычки

### Верификация Telegram пользователя

Для активации напоминаний через Telegram пользователь должен верифицировать свой аккаунт вводом кода.
Код автоматически присылается пользователю при регистрации в приложении или при добавлении Telegram username
при редактировании профиля, но при условии, что пользователь до этого начал чат с ботом командой /start.

Ввод кода верификации происходит после авторизации пользователя на странице
    
    %user_id%/telegram_verification
